# MTD Income Tax API Discovery

## Objective

Identify and explain the correct HMRC API for
a Making Tax Digital for Income Tax requirement.

## Scope

Only investigate APIs related to MTD Income Tax.

Do not research or recommend APIs for MTD VAT,
PAYE, Corporation Tax, or unrelated HMRC products.

## Workflow

1. Understand the MTD Income Tax business requirement.
2. Search the HMRC API catalogue.
3. Identify APIs explicitly related to MTD Income Tax.
4. Retrieve the relevant API documentation.
5. Retrieve the technical specification.
6. Identify the endpoint and HTTP method.
7. Identify authentication and authorisation requirements.
8. Identify request and response schemas.
9. Check API status and version.
10. Check relevant MTD Income Tax service guides,
    testing guides, and roadmaps.

## Output

Provide:

- API name
- Business purpose
- API version and status
- Endpoint
- HTTP method
- Required scopes
- Required headers
- Request schema
- Response schema
- Error codes
- Official documentation links

Do not invent missing information.

If multiple MTD Income Tax APIs could satisfy
the requirement, explain their differences.

If the API's relevance to MTD Income Tax cannot
be verified, report the uncertainty.
